## Crawdaunt 🦞

Crawdaunt is a crawling tool used for a PokeApp (name in progress). It crawls
official pokemon.com pokedex. It gathers relevant data and formats it into
pokemon.json. Secondly it downloads oficial artworks into images folder.

# Installation

```bash
git clone
cd crawdaunt
deno install
deno run configure
```

# Usage

```bash
deno run main.ts
```

# Tech Stack

- Deno
- Playwright
